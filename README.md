# Road to War: five places, one story

An interactive tour of five areas of the South African War, linked in the order the events happened:
1. Gold and the Jameson Raid (Witwatersrand, Johannesburg, Doornkop)
2. Spion Kop (January 1900)
3. Paardeberg (February 1900)
4. Bloemfontein, the Old Presidency (March 1900)
5. Pretoria (June 1900)

## Files (upload everything, including the img folder, to the same GitHub repository)
- `index.html`: the tour. If your repository already has an index.html, upload the new one and choose to replace it.
- `road-to-war-google-earth.kml`: the same five areas for the real Google Earth.
- `img/`: the photographs from your document.
- `README.md`: this file.

## Publish on GitHub Pages
Settings > Pages > Deploy from a branch > `main` and `/ (root)` > Save. Your tour is then at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Open the Google Earth file
Go to earth.google.com/web, open the menu, choose **Projects > New project > Import KML file**, and pick the .kml file. Click **Present** to fly between the stops.

## Notes
- The scenes are illustrations drawn in code, not photographs. The map uses Esri satellite imagery.
- Before submitting, add the archive credit and licence check for any historical photograph you add.
